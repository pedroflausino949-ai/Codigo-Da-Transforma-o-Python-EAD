# Módulo 12 - Testes Automatizados

Projeto de testes automatizados usando Python e unittest.

## Arquivos

- `calculadora.py` - classe Calculadora.
- `test_calculadora.py` - testes das operações matemáticas.
- `frete.py` - função para calcular o valor do frete.
- `test_frete.py` - testes do sistema de cálculo de frete.

## Como executar no VS Code

Abra o terminal na pasta `Modulo_12` e execute:

```bash
python -m unittest discover -v
```

Se o comando `python` não funcionar no Windows, tente:

```bash
py -m unittest discover -v
```

Os testes devem terminar com `OK`.
